AeniaFlow 2.8 — готовая сборка

1. Остановите старый процесс. Сохраните свои .env, owner_config.json и data.
2. Распакуйте архив целиком. В персональном архиве прежний токен сохранён.
   Более свежую локальную .env оставьте своей. Базу и папку data не удаляйте.
3. Windows: START_WINDOWS.bat. Linux/macOS: bash START_LINUX_MACOS.sh.
   Вручную: python -m pip install -r requirements.txt
            python check_setup.py
            python main.py
   Работать должна одна копия бота.
4. В ЛС бота: .AdminMenu. Владелец 8478693660 и админ 8285233133 имеют Plus.
   Пользователи, Plus, бан, рассылки, канал, ключ ИИ — в этой панели.
5. Бесплатным пользователям нужна подписка на канал @AeniaFlow.
   Назначьте бота администратором канала. Изменить канал: .AdminMenu.
   Для Plus и администраторов подписка на канал необязательна.
6. Подключение: Профиль → Подключение ЛС → Инструкция.
   Картинка также в assets/connect.png. Проверка: .ping и .calc 2+2.
7. .menu/Start теперь удаляет прежнее меню и присылает новое.
   Кнопки внутри меню меняют текущую карточку. Результат функции — отдельно.

Схема базы обновляется до 8 автоматически с резервной копией .bak.
Отзыв Plus — не возврат Stars. Реферальные 50% — внутренний учёт и заявка
на ручную выплату; кнопка администратора сама Stars никому не переводит.

Все команды: COMMAND_INDEX.md. Установка: README_RU.md и HOSTING_SETUP.md.
