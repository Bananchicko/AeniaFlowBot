# AeniaFlow 2.8 — запуск и подключение

## Обновление

Остановите предыдущую копию. Скопируйте `.env`, `owner_config.json` и `data` в безопасную папку. Распакуйте новый архив с сохранением своей актуальной конфигурации и базы. Код модульный, обычные UTF-8 файлы без минификации; ZIP без сжатия. Не запускайте две копии одновременно.

Нужен Python 3.11 или новее. Установите `python -m pip install -r requirements.txt`, выполните `python check_setup.py`, затем `python main.py`. Проверка установки не вызывает Telegram и не проверяет действительность токена по сети. При запуске в журнале будет `AeniaFlow 2.8 started`.

`START_WINDOWS.bat` и `START_LINUX_MACOS.sh` выполняют эти шаги. На хостинге используйте постоянно работающий процесс; веб-сервер для polling не нужен. Переменные хостинга имеют приоритет над `.env`. Если токен в панели хостинга устарел, изменение файла не заменит его. Не отправляйте токен в поддержку и не публикуйте личный архив.

База: `data/aeniaflow.sqlite3` по умолчанию. Миграция до схемы 8 создаёт `.bak`. Для переноса живой базы используйте `scripts/backup_db.py`, а не копирование одного файла SQLite без остановки: данные могут находиться также в WAL. Для Docker сохраняйте том `./data`; настройки показаны в `docker-compose.yml`.

## BotFather — один раз владельцу бота

1. Откройте настоящий [@BotFather](https://t.me/BotFather).
2. Отправьте `/mybots`, выберите своего бота и откройте Bot Settings.
3. Включите **Secretary Mode**. В некоторых интерфейсах пункт называется **Business Mode**. Он разрешает подключать бота к аккаунтам пользователей.
4. Privacy Mode относится к группам и не исправляет права в личных чатах. Получать права администратора группы этому боту не нужно.

Токен уже сохранён в персональной сборке. Пользовательский статус владельца BotFather сам по себе не заменяет роли приложения: владелец `8478693660` задан в `owner_config.json`, дополнительными администраторами управляйте через `.AdminMenu`.

## Telegram пользователя — подключить свои ЛС

1. Откройте ЛС самого бота и нажмите «Начать». Возьмите его @username из профиля: имя канала @AeniaFlow не обязательно совпадает с username бота.
2. В Telegram откройте Настройки → Telegram Business → Чат-боты. Добавьте этого бота.
3. Выберите нужные личные диалоги с людьми. Проверьте, что конкретный собеседник не исключён и обработка не приостановлена кнопкой управления ботом в чате.
4. Разрешите **ответы**, **удаление всех сообщений**, а для `.read` и `.autoread` — **чтение сообщений**. Одного права удаления отправленных ботом сообщений недостаточно для `.mute` и удаления вашей команды.
5. В ЛС бота откройте `.connect` → «Проверить права». В доступном личном диалоге сами отправьте `.ping`, затем `.calc 2+2`.

Для Business-ответов Telegram требует входящее в выбранном ЛС за последние 24 часа. Собственное исходящее не заменяет входящее. В ЛС самого бота это ограничение Business не действует. `/start` в подключённых чужих диалогах не запускает команды: используйте точку. Инструкция-картинка — `assets/connect.png`.

Если бот уже был подключён до установки, событие из выбранного ЛС восстанавливает соединение по его ID. Не нужен ручной ввод ID собеседника. Если после смены прав статус не обновился, используйте «Проверить права»; при отсутствии событий переподключите бота в Telegram Business.

## Обязательный канал

Для бесплатного доступа нужна подписка на канал бота. По умолчанию это `@AeniaFlow`; пустая настройка её не выключает. Откройте канал → управление → администраторы → добавьте именно этого бота. Подписку других пользователей Telegram надёжно проверяет, когда бот — администратор канала.

Изменить публичный канал: `.AdminMenu` → «Канал подписки». Панель проверит права бота и сохранит настройку в базе. Она важнее `NEWS_CHANNEL` из файла. Если `getChatMember` вернул ошибку, бесплатные функции остаются закрыты, а сообщение показывает причину; проверка не выдаёт доступ автоматически. Действующий Plus и роль администратора пропускают эту проверку.

## ИИ и голос

Ключ: `.AdminMenu` → «Ключ и модель ИИ» → «Изменить API-ключ». Введите API-ключ OpenAI целиком; сообщение удаляется, значение сохраняется в базе. Модель задаётся соседней кнопкой. Альтернативные настройки `OPENAI_API_KEY` и `OPENAI_MODEL` в `.env` продолжают работать, если в базе нет переопределения. Ключ и модель должны быть доступны вашему API-проекту. Подписка ChatGPT не служит балансом OpenAI API.

`.msay` не использует ключ OpenAI. Ему нужны доступ к Google TTS и готовый FFmpeg; ответ — голосовое OGG/Opus. Встроенная проверка FFmpeg смотрит не только наличие файла, но и запуск нужных кодеков. См. `FFMPEG_SETUP.md`.

## Диагностика

| Симптом | Что проверять |
| --- | --- |
| `MESSAGE_ID_INVALID` при редактировании меню | Бот создаёт новую карточку. Старая могла быть удалена или недоступна; перепривязка только из-за этой ошибки не требуется. |
| `getChatMember` | Канал, его username и роль бота в канале. Это не права Telegram Business. |
| `BUSINESS_CONNECTION_INVALID` | Соединение могло быть отключено или заменено. Переподключите бота и дождитесь события. |
| Ошибка Business-отправки | Право ответа, выбранный диалог, пауза, последнее входящее за 24 часа. |
| Ошибка `deleteBusinessMessages` | Право удаления всех сообщений, доступность и возраст удаляемого сообщения. |
| Бот молчит даже на `.ping` в своих ЛС | Процесс, версия 2.8, токен в переменных хостинга, только одна копия; для бесплатного аккаунта также канал и режим обслуживания. |
| `.msay` или кружок не получаются | `python check_setup.py`, FFmpeg и сетевой доступ TTS. |
| Нет Plus у владельца | Убедитесь, что `owner_config.json` распакован рядом с `config.py`, и перезапустите актуальный процесс. |

Администратор может открыть `.AdminMenu` даже при обслуживании и возобновить работу. Реальные серверные ошибки не скрываются под сообщением об успешном действии.

Официальные справочники: [Business-боты](https://core.telegram.org/bots/features#business-bots), [права Business](https://core.telegram.org/bots/api#businessbotrights), [проверка подписки](https://core.telegram.org/bots/api#getchatmember). Названия пунктов в клиентах Telegram могут немного различаться.
