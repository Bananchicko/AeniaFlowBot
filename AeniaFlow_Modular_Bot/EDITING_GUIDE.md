# Редактирование AeniaFlow 2.7

Архив ZIP сохранён без сжатия. Распакуйте его целиком перед запуском или редактированием. Исходники обычные, с отступами и раздельными файлами.

- Токен и начальные настройки: `.env`. Хостинг может задавать переменные окружения; непустые переменные имеют приоритет. BOT_TOKEN не меняется обновлением кода.
- Владелец и начальный дополнительный администратор: `owner_config.json`. Сохраните этот файл при обновлении.
- Новые администраторы, отзыв доступа, API-ключ и модель: `.AdminMenu` в ЛС самого бота. Настройки сохраняются в `data/aeniaflow.sqlite3` и применяются сразу.
- Покупки, чаты, муты, заметки, быстрые ответы, состояние меню: папка `data`. При смене хостинга переносите всю папку при остановленном процессе.
- Основные экраны: `aeniaflow/handlers/system/sections.py`.
- Админ-меню: `aeniaflow/handlers/system/admin_menu.py`.
- Карточки и переходы: `aeniaflow/core/ui.py`, `aeniaflow/core/responses.py`.
- Каталог и порядок функций: `aeniaflow/catalog.py`, `aeniaflow/core/navigation.py`.
- Серии сообщений: `aeniaflow/handlers/commands/message_series.py`.
- Команды личных диалогов: `aeniaflow/handlers/commands/dialog_tools.py`.

Перед изменением кода сохраните копию `.env` и `data`. Разрабатывать и запускать тесты можно в отдельной копии проекта: `python -m pip install -r requirements-dev.txt`, затем `python -m pytest -q`. Тесты не используют действующий токен и не отправляют запросы в Telegram или OpenAI; FFmpeg проверяется на локальных файлах.
