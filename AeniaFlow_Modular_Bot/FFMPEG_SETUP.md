# FFmpeg в AeniaFlow 2.7

В `requirements.txt` добавлен `imageio-ffmpeg==0.6.0`. Платформенные wheels содержат готовую программу FFmpeg, которую бот находит автоматически. Для обычного поддерживаемого Linux/Windows/macOS не нужно вручную распаковывать исходники:

```sh
python -m pip install -r requirements.txt
python check_setup.py
python main.py
```

Скрипты START_WINDOWS.bat и START_LINUX_MACOS.sh выполняют установку и проверку перед запуском. Dockerfile дополнительно устанавливает системный FFmpeg через apt.

Ваш файл `ffmpeg-9.0.2.tar(1).xz` проверен: 10 525 элементов, включая `configure`, `Makefile` и исходники библиотек. В нём нет готовых `ffmpeg`, `ffmpeg.exe` или `ffprobe`. Он не включён повторно в архив бота и не запускается как программа. Сборка из этих исходников требует компилятора и отдельных библиотек кодеков; для запуска бота используется готовая сборка.

## Порядок поиска

1. Явный `FFMPEG_PATH` — путь к исполняемому файлу. Неверное явное значение не игнорируется.
2. `bin/ffmpeg` или `bin/ffmpeg.exe` внутри проекта.
3. Системный `ffmpeg` из PATH.
4. Готовая программа из установленного `imageio-ffmpeg`.

На редкой архитектуре, при установке пакета из исходников вместо wheel или запрете исполняемых файлов хостингом готовая программа может не установиться. Используйте системный FFmpeg, Docker или подходящую программу по FFMPEG_PATH. Linux ARM и Linux x86_64 требуют разных сборок. Windows EXE не работает на Linux.

## Проверка

`python check_setup.py` и `.status` проверяют возможность запуска FFmpeg и наличие `libx264`, `libopus`, `aac`, `libmp3lame`. Это локальная проверка; она не проверяет права Telegram.

В проверенной Linux x86_64 сборке imageio используется FFmpeg 7.0.2-static. Кодеки найдены, реальная конвертация тестового видео в кружок прошла. Использование приложенного архива 9.0.2 как исполняемого файла не заявляется.

`.msay` выдаёт голосовое OGG/Opus. `.videonote` создаёт квадратное видео H.264/AAC, до 60 секунд, которое отправляется Telegram методом sendVideoNote. `.audio` извлекает звук. Файлы обрабатываются локально и удаляются после отправки или ошибки. Для gTTS нужен доступ хостинга в интернет; OpenAI API-ключ для `.msay` не нужен.

Источники: [FFmpeg downloads](https://ffmpeg.org/download.html), [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg), [релиз 0.6.0](https://pypi.org/project/imageio-ffmpeg/0.6.0/).
