# Обложки AeniaFlow 2.2

Три новые растровые обложки созданы встроенным imagegen и включены в проект. Режим: генерация новых изображений, без исходного изображения; прозрачность выключена. CLI и API-ключ не использовались.

| Файл | Экран |
| --- | --- |
| `assets/home.png` | Главная, каталог, органайзер, профиль |
| `assets/dialogs.png` | Личные чаты, подключение, автоответчик |
| `assets/plus.png` | Plus и его возможности |

Промпты-брифы:

1. **Главная.** Широкая обложка Telegram-бота AeniaFlow. Светлый фон цвета слоновой кости, кобальтовый синий, чёрная редакционная типографика, объёмная плавная форма буквы A. Текст: «AeniaFlow», «Личные чаты. Твой порядок.». Чистая выразительная композиция, свободное пространство. Без нарисованных кнопок, рамки приложения, имитации интерфейса и водяных знаков.
2. **Личные чаты.** Широкая обложка той же визуальной серии: слоновая кость, кобальтовый синий и чёрный. Две абстрактные формы диалога, синий и тёмный объекты, знак паузы. Текст: «AeniaFlow», «Личные чаты». Чёткая типографика, чистая композиция. Без нарисованных кнопок и интерфейсных контролов.
3. **Plus.** Широкая обложка той же серии: светлый фон цвета слоновой кости, кобальтовая четырёхлучевая звезда, чёрная типографика. Текст: «AeniaFlow+», «Больше возможностей». Выразительный объёмный объект, аккуратные свет и тени. Без тарифных карточек, ложных кнопок и интерфейса внутри изображения.

Картинки содержат только оформление. Все действия задаются через `InlineKeyboardMarkup` в коде. Изображение отправляется через `sendPhoto`, переходы — `editMessageMedia`. Возвращённые Telegram file_id кэшируются в памяти процесса по боту и имени обложки. Длинный текст выводится отдельно от обложки, без обрезки до лимита подписи.

## Шрифты 2.3

В `assets/fonts/` включены DejaVu Sans Regular, Bold и Mono Oblique для одинакового отображения кириллицы на Windows и Linux. Условия распространения: `assets/fonts/LICENSE.txt`. Обложки 2.2 сохранены; изменения 2.3 касаются настоящих кнопок и рендеринга водяных знаков в коде.

## Подключение ЛС (2.8)

`connect.png` — точная инструкция с четырьмя шагами, `connection_guide.pdf` — версия для чтения и печати. Иллюстрация `connection_illustration.png` создана imagegen; надписи сверстаны отдельно, кнопок внутри картинки нет. Пересборка: `python scripts/build_connection_guide.py` (только для дизайна, требует ReportLab и Poppler). Эти зависимости не нужны для работы бота.
